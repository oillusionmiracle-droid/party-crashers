Lagos-first event discovery

Party
Crashers

A fun, editorial, motion-led web app for discovering what Lagos is doing — tech, business, campus, culture, music, parties and everything in between.

Core rule: typography and graphics are the animation. No floating AI blobs, no glass-card soup, no “make it modern” filler.
01 / Brand thesis

Lagos is doing something. Find it.

Useful first

Every screen must help someone find, understand, save, share or register for an event.

Editorial, not SaaS

Layouts should feel like a city guide, festival programme and motion poster — not a dashboard template.

Fun through craft

Energy comes from kinetic type, hard cuts, map graphics, event posters and confident composition.

02 / Reference board

What we are actually borrowing

External references worth studying: Resident Advisor for editorial event density; Partiful for social energy and organizer customization; Luma for frictionless event creation and map/discovery; ART X Lagos and Design Week Lagos for locally grounded cultural confidence.
03 / Typography

Two-font system

Display / brand — Artific (provisional)
Lagos is outside.

Use for the wordmark, large location names, campaign statements, onboarding reveals and motion typography. Prefer Regular / SemiBold / Black; oblique only as an accent.

UI / information — Space Grotesk
FRI 23 OCT · 6:30 PM
National Theatre, Iganmu · Free
Technology · Networking · Lagos

Use for map labels, metadata, filters, forms, buttons, organizer information and body copy.

Type behavior

Big headlines can be uppercase, tight-tracked and aggressively scaled. UI copy stays calm, readable and mostly sentence case.

Do not

Do not add a third “cool” font just to create variety. Variety should come from scale, composition, weight and motion.

Production motion stack

GSAP SplitText for line/word/character choreography; GSAP Flip for poster → event-page transitions; ScrollTrigger for scrubbed typography and map-route moments. Normal UI interactions stay lightweight.

Motion timing: micro 140–220ms; interface 240–380ms; signature sequences 500–900ms. Prefer snap, masks, perspective and hard cuts over endless easing.

06 / Graphic asset library

Visual assets that belong to the product

City graphics

Simplified Lagos routes, venue silhouettes, road signs, bus/transport motifs, street-grid fragments and recognizable architecture drawn as flat graphic forms.

Event objects

Tickets, wristbands, stamps, speaker stacks, passes, arrows, map pins, schedule strips and poster frames.

Real content

Organizer posters and photography should carry most of the visual richness. The system frames real culture instead of generating filler imagery.

07 / First 60 seconds

Storyboard before screens

Open

PARTY CRASHERS slams in. Lagos route draws behind it. 0.8–1.2s max.

Clerk sign-in

Minimal auth. No carousel, testimonials or fake product copy.

Interests

Choose at least 3. Selected words lock into a typographic composition, not floating cards.

Area + campus

Pick Yaba / Ikeja / VI / etc. Optional campus. Location permission comes later.

Reveal

“42 things match you.” A hard-cut Lagos title gives way to the actual event feed.

08 / Core product surfaces

Design these before anything else

Discover

Editorial feed. Today / Weekend / Free / Campus / Tech. Mix poster sizes; avoid an endless same-card grid.

Map

Full-screen Lagos map + bottom sheet. Pins use category accents. Selecting a district can trigger a giant location-name transition.

Event detail

Poster, title, date/time, location, price, organizer and a dominant external Register button.

Post event

Two entry points: Upload flyer / Create manually. Publishing ends with “YOU’RE ON THE MAP.”

Saved

Chronological event plan rather than a generic bookmark gallery. Detect time conflicts.

Profile / organizer

Interests, campus, saved events, created events and basic referral/registration-click stats.

09 / No-slop rules

What is banned

DO

  • Use real event artwork and photography.
  • Build motion around typography and information.
  • Allow layouts to change rhythm and scale.
  • Use hard edges, strong crops and deliberate whitespace.
  • Make Lagos visible through actual places and map logic.

DON’T

  • No random glowing 3D blobs or floating glass objects.
  • No purple-blue gradient as the default background.
  • No 24px-rounded card on every element.
  • No fade-up animation repeated down the entire page.
  • No generic AI portraits as visual filler.
10 / Build handoff

Implementation constraints

Frontend

Next.js + TypeScript. Clerk for auth. GSAP for signature motion. Mapbox for the Lagos map. Responsive mobile-first layout.

Accessibility + performance

Respect prefers-reduced-motion. Never hide essential information behind animation. Animate transforms/opacity first. Lazy-load poster media. Keep the map usable on lower-end Android devices.

Research notes

Why these decisions hold up

Current event products reinforce the key product primitives: local discovery, map browsing, organizer-created event pages and easy registration. Luma currently supports search, map discovery, city/category browsing and personalized feeds. Partiful emphasizes fast event creation, customizable visual identity and local Explore discovery. For Lagos grounding, Design Week Lagos explicitly treats the city itself as a distributed stage, while ART X Lagos mixes art, music, film, design and talks under one cultural umbrella.

Font status: Artific is a commercial family by Power Type / Teguh Arief. Keep it provisional until a web license is purchased. Space Grotesk remains the UI workhorse.
