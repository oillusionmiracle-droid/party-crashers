# Downloaded navigation assets

The five unmodified SVGs under `tabler/` were downloaded from https://github.com/tabler/tabler-icons/tree/main/icons/outline. MIT licence is included as `tabler/LICENSE`.

Mappings: compass → Discover; map-2 → Map; square-rounded-plus → Post; bookmark → Saved; user-circle → Profile. CSS uses the SVG files as masks to inherit the app's light/dark/active colours. No replacement paths were drawn.

`/assets/brand/google-g.png` was downloaded from Google's official branding page: https://developers.google.com/static/identity/images/g-logo.png. It remains the standard full-colour Google G, on white, without recolouring, as specified at https://developers.google.com/identity/branding-guidelines. It is Google's trademark and is not covered by Tabler's MIT licence.
